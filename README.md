# Семейный микс — Путешествие по Казахстану 🇰🇿

Семейная браузерная игра: карта Казахстана, кубик, фишки и викторина в стиле Kahoot в каждом городе.
Играют с разных телефонов (iPhone, Samsung/Android, компьютер) по секретному коду комнаты из 6 цифр.

Автор идеи: Аниса.

## Как запустить локально
```
cd /workspace/family-mix && python3 -m http.server 8765
# открыть http://localhost:8765/
```
Для игры с телефона нужен адрес https:// (например GitHub Pages): браузеры дают шифрование только на защищённых страницах.

## Как устроена сеть
- Своего сервера нет. Сообщения идут через несколько бесплатных публичных Nostr-релеев (обычный WebSocket на 443 порту), список в `js/net.js`.
- Каждое сообщение шифруется AES-GCM ключом из кода комнаты и отправляется сразу во все релеи; дубликаты отбрасываются. Если какой-то релей не работает, игра идёт через остальные.
- Главный — ведущий (тот, кто создал комнату): только он бросает кубик, считает очки и рассылает общее состояние.
- Ведущий может перезагрузить страницу: кнопка «Вернуться в игру» восстанавливает партию (сохранено в localStorage).

## Публикация на GitHub Pages
Залить содержимое этой папки в репозиторий (кроме `dev/node_modules`) и включить Pages. Сборка не нужна.
При обновлении файлов поменяй `VERSION` в `sw.js`.

## Файлы
- `index.html`, `style.css` — интерфейс
- `js/app.js` — экраны, карта, викторина, режим автора, пасхалки
- `js/game.js` — правила игры (работает у ведущего)
- `js/net.js` — сеть через Nostr-релеи
- `js/data.js` — города, клетки-сюрпризы, 83 вопроса
- `js/map-geo.js` — контур Казахстана (Natural Earth, public domain)
- `vendor/nostr-sign.min.js` — подпись событий Nostr (nostr-tools, MIT), собрано esbuild
- `dev/` — тесты (`mp-test.js` — 3 «телефона» в одной комнате, `extra-test.js`, `logic-test.mjs`)
